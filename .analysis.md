# OTP Admin Panel Bug Analysis

## Issues Found

### 1. Missing `custom_permissions` in saveUserDetails payload
- **Location**: AdminPanel.js, saveUserDetails function (line 1155-1210)
- **Issue**: The payload being sent to the API doesn't include `custom_permissions`
- **Impact**: 
  - Backend receives custom_permissions as undefined
  - Backend then passes `custom_permissions || {}` which is an empty object
  - This overwrites any existing custom_permissions with an empty object
  - Permissions like `bulk_upload` are lost when saving user details

### 2. Potential Boolean handling issue in response
- **Location**: AdminPanel.js, saveUserDetails response handling (line 1191)
- **Code**: `otp_enabled: res.data?.otp_enabled !== false`
- **Issue**: This converts undefined to true, which might mask other issues

## Solution
Include `custom_permissions` in the saveUserDetails payload to preserve user permissions when updating other fields (including OTP settings).
